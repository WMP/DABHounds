Hi! I've prepared a large PR with comprehensive library management functionality for DABHounds.

The feature adds both interactive TUI mode (with curses) and CLI commands for viewing, managing, and cleaning up DAB libraries. Key features include:
- Full-screen interactive browser with arrow key navigation
- Duplicate detection using ISRC + fuzzy matching (found 19 groups in my 322-track library)
- Bulk operations: select, delete, export to JSON/CSV
- Smart caching system (15 seconds → <1 second for repeated operations)
- Library search by name, interactive library picker
- Proper pagination support for large libraries

Everything is well-documented (3 doc files + updated README), tested extensively, and backward compatible. The PR is ready for review: https://github.com/WMP/DABHounds/pull/new/feature/library-manager
